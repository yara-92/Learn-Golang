这是什么

这是一个用来演示 Hugo 静态网站生成器完整工作流的示例工程，目录结构清晰、可直接下载后本地启动预览。

项目特点

  • 完全自定义主题（未依赖任何第三方 theme），便于理解 Hugo 模板机制的每一层
  • 包含首页、文章列表页、文章详情页、独立页面（关于）四种典型页面类型
  • 使用 baseof.html + block 实现模板继承
  • 使用 partials 拆分页头、页脚，便于复用
  • 内置标签（tags）与分类（categories）两种分类法
  • 自带一份精简、无外部依赖的 CSS 样式

技术栈

Hugo 是使用 Go 语言编写的静态网站生成器，以构建速度极快著称，无需数据库和运行时后端，生成的是纯静态 HTML/CSS/JS 文件，可以部署到任意静态托管平台。
